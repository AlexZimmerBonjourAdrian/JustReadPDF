PLAN DE IMPLEMENTACIÓN - JustReadPDF

ARQUITECTURA: Componentes profesionales + Procesamiento local

OBJETIVO:
Convertir PDF en HTML con formato (negritas, cursivas, estructura) para traducción manual.
Procesamiento 100% en el navegador sin backend.

FASE 1: Configuración básica ✓ COMPLETADO
- Configurar Next.js 16.1.6 con TypeScript
- Configurar TailwindCSS v4
- Estructura inicial de componentes

FASE 2: Visualizador profesional ✓ COMPLETADO
- Instalar @shahajimbhosle/local-doc-viewer
- Integrar DocumentViewer con modo oscuro
- Configurar controles: zoom, búsqueda, impresión
- Soporte multi-formato (PDF, HTML, DOCX, TXT)

FASE 3: Extracción de texto con formato ✓ COMPLETADO
- Instalar extract-pdf
- Implementar conversión PDF → HTML estructurado
- Mantener negritas, cursivas, headings H1-H6
- Detección automática de listas y párrafos
- Procesamiento local (sin servidor)

FASE 4: Interfaz de usuario ✓ COMPLETADO
- Input file para carga de PDF
- Estados de carga y error
- Visualización del HTML resultante
- UI con modo oscuro integrado

FASE 5: Próximas mejoras (PENDIENTE)
- [ ] Exportar HTML para traducción externa
- [ ] Integrar API de traducción (Google Translate, etc.)
- [ ] Procesamiento por páginas/bloques
- [ ] Caché de conversiones
- [ ] Soporte para PDFs escaneados (OCR)

ENFOQUE ACTUAL:
Uso de componentes profesionales probados en lugar de desarrollo desde cero.
Procesamiento 100% client-side para privacidad y velocidad.
