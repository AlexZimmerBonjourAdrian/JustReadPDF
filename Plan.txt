PLAN DE IMPLEMENTACIÓN - JustReadPDF

ARQUITECTURA: Vertical Slice (básico)

OBJETIVO:
Convertir PDF en texto para traducción manual en ventana de preview colapsable.
Procesar por bloques (páginas) no todo a la vez.

FASE 1: Configuración básica
- Limpiar page.tsx actual
- Configurar estructura inicial
- Preparar estados principales

FASE 2: Carga de PDF
- Implementar input file
- Manejo de estado del archivo cargado
- Validación de archivo PDF

FASE 3: Extracción de texto
- Integrar react-pdf
- Extraer texto página por página
- Procesar en bloques individuales
- Limpiar y ordenar texto

FASE 4: Ventana de preview
- Crear ventana colapsable
- Mostrar texto organizado por páginas
- Implementar botón minimizar/maximizar
- Estilizar con TailwindCSS

FASE 5: Refinamiento
- Extraer componentes si es necesario
- Mejorar UX
- Testing básico

ENFOQUE VERTICAL SLICE:
Cada fase builds sobre la anterior, manteniendo funcionalidad
completa y funcional en cada iteración.

DEPENDENCIAS EXISTENTES:
- react-pdf (v10.4.1) ✓
- Next.js 16.1.6 ✓
- TailwindCSS ✓
